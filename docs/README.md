# Section Selection Scheduling, a Study of the YU-Sync Engine

This directory contains a self-contained study of the problem solved by the
YU-Sync course scheduler and of the depth-first search with bitmask conflict
detection that solves it. It is written to be read on its own. Every proof,
figure, table and methodological detail needed to review the work is present in
these Markdown files. The application in [`app/`](../app) provides interactive
counterparts to several figures, but nothing here depends on running it.

## Conventions

Citations follow the **IEEE** style. References are numbered in
[09-references.md](./09-references.md) and cited in text as [1], [2] and so on.

Mathematics is written in LaTeX and renders natively on GitHub. Inline
expressions use `$...$` and display expressions use `$$...$$`.

Claims are separated into three kinds and are labelled as such throughout.

- **Proved.** A theorem with a written proof in this directory.
- **Measured.** A quantity produced by a stated experiment at a stated seed, with
  the raw output committed under [`data/`](./data).
- **Cited.** A result taken from the literature, with a reference.

Anything that is none of these is stated as an observation and marked as one.

## Reproducing the results

```bash
cd app
npm install
npm run bench     # regenerates docs/data and docs/figures
npm run test      # runs the parity test that Theorem 6 depends on
```

The structural measurements are fully determined by the seeds recorded in each
JSON file and reproduce byte for byte on any machine. Wall-clock and
nanosecond measurements depend on hardware and load and are reported separately
under a `timing` key for exactly that reason. The environment used for the
figures published here is recorded in
[`data/environment.json`](./data/environment.json).
